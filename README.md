# smart-parking-lot-management
A Python OOP project that simulates a smart parking lot system using classes, objects, methods, and lists. It manages vehicle parking, removal, available slots, and duplicate vehicle registration checks.
<br>
Topics Covered:
<br>

1. Class and Objects
2. Constructor (__init__)
3. Class Attributes
4. Instance Attributes
5. Instance Methods
6. Encapsulation
7. Lists and List Methods
8. Conditional Statements (if-elif-else)
9. Loops (while and for)
10. User Input (input())
11. Exception Handling (try-except)
12. Functions and Methods
13. Return Statements
14. Main Function (main())
15. Dunder Method (__name__ == "__main__")
